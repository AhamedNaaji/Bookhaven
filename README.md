# BookHaven - Bookstore Management System

BookHaven is a comprehensive Windows Forms-based desktop application designed to modernize and streamline the operations of mid-sized bookstores. With a focus on inventory management, sales tracking, customer management, and robust security, BookHaven empowers bookstore staff and administrators to efficiently manage daily business processes.

## Features

- **User Login System**
  - Secure authentication with role-based access control (Admin, Sales Clerk)
  - Different access permissions based on user roles

- **Book Inventory Management**
  - Add, update, delete, and search for books
  - Track details: title, author, genre, ISBN, price, stock quantity

- **Customer Management**
  - Create and manage customer profiles
  - Store contact info and purchase history

- **Sales Transaction (POS)**
  - Select books for purchase, calculate totals, apply discounts
  - Generate sales receipts and update inventory in real-time

- **Order Management**
  - Track and manage customer orders (in-store pickup or delivery)
  - Update order status and details

- **Supplier Management**
  - Manage supplier information (publishers, distributors)
  - Generate purchase orders as inventory runs low

- **Admin Dashboard**
  - Overview of sales, inventory, customer activity, and staff performance
  - Access to settings and user management

- **Reporting and Analytics**
  - Generate daily, weekly, and monthly sales reports
  - Highlight best-selling books and inventory status

- **Security & Data Protection**
  - Role-based access control, encrypted sensitive data
  - Secure customer information storage

## Installation

1. **Prerequisites:**
   - Windows 10/11
   - .NET Framework 4.7.2 or above
   - Visual Studio 2019 or later (for development)

2. **Clone the Repository:**
   ```bash
   git clone https://github.com/AhamedNaaji/Bookhaven.git
   ```

3. **Open Solution:**
   - Open the `.sln` file in Visual Studio.

4. **Restore NuGet Packages:**
   - Visual Studio should prompt to restore packages. If not, right-click on the solution and select "Restore NuGet Packages."

5. **Build and Run:**
   - Press `F5` or click "Start" to build and launch the application.

## Usage

- On launch, staff log in using their credentials.
- Navigate using the sidebar/menu to access Inventory, Sales, Orders, Customers, Suppliers, and Reports.
- Admin users can access the dashboard and settings for advanced management.
